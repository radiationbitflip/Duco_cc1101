# duco-rf-sniffer and controller 

Experimental local DUCO RF sniffer and controller using ESP32 and CC1101.

## Contents

- `duco_cc1101_sniffer` - CC1101 DUCO RF sniffer
- `duco_cc1101_controller` - CC1101 DUCO RF command transmitter

## Hardware

- ESP32
- CC1101 868 MHz module

## Warning

This project is intended only for controlling DUCO systems that you own or are authorized to manage.

Do not transmit RF commands to devices that are not yours.

## Status

Experimental. Packet format and command replay behavior may vary between DUCO installations.
